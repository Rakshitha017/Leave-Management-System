Leave Management System

Overview

A Java-based application designed to manage employee leave requests and approval workflows using Object-Oriented Programming (OOP) concepts.

Features

- Employee details management
- Leave request submission
- Leave approval and rejection
- Input validation and exception handling
- Modular code structure and refactoring

Technologies Used

- Java
- Object-Oriented Programming
- Git and GitHub

Learning Objectives

- Apply encapsulation, inheritance, polymorphism, and abstraction where appropriate.
- Improve code readability and maintainability.
- Practise debugging, testing, and version control.
